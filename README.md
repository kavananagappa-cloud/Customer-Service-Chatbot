
# Customer Service Chatbot Using NLP

## Project Description
This project develops a customer service chatbot using Python and Natural Language Processing (NLP).

The chatbot understands basic customer questions and provides automatic responses.

## Technologies Used
- Python
- Google Colab
- Natural Language Processing
- Scikit-learn
- TF-IDF
- Cosine Similarity

## Features
- Greeting messages
- Product information
- Delivery information
- Order tracking guidance
- Return and refund information
- Payment information
- Customer support details

## How to Run
1. Download the project notebook.
2. Open Google Colab.
3. Upload the notebook.
4. Run all code cells.
5. Enter customer questions and receive responses.

## Project Objective
To develop a simple NLP-based chatbot that answers basic customer queries automatically.
